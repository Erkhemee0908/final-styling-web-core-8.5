# Responsive Service Page

Web Core, Final Styling (Lesson 8.5)

## Built with

- HTML
- SCSS
- JavaScript
- [webpack 5](https://webpack.js.org/), based on [webpack-static-template](https://github.com/Habsida-Projects/webpack-static-template)
- [Swiper](https://swiperjs.com/) (via npm)
- TT Lakes font

## Getting started

```bash
npm install
npm start
```

| Command | What it does |
|---|---|
| `npm start` | Runs the dev server at http://localhost:9000 |
